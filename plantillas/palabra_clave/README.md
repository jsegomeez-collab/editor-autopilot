# palabra_clave

**Cuándo:** cuando se dice una idea clave corta (1–3 palabras literales) y ninguna otra plantilla encaja. Es la plantilla de respaldo: funciona con cualquier texto corto.

**Qué muestra:** el texto en serif itálica grande y blanca (fuente "Enfasis"), como "Build by NVIDIA" o "un solo lugar" en los vídeos de referencia. Las palabras de `destacado` van en el color de acento.

**Animación:** palabra a palabra (o letra a letra si es una sola palabra): cada unidad entra con desenfoque, escala y subida suaves. La última aterriza exactamente en `t_aterrizaje` y las anteriores, escalonadas justo antes. Después, deriva suave del texto y del resplandor hasta el final.

**Datos:** ver `schema.json`.
