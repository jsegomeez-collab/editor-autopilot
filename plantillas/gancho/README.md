# gancho

**Cuándo:** siempre en la primera ventana del vídeo (split en el frame 0).

**Qué muestra:** la promesa o tesis del gancho con palabras literales del vídeo (≤ 4 palabras, siempre en 2 líneas como máximo). Las palabras de `destacado` llevan un barrido del color de acento.

**Animación:** el titular ya se lee en el frame 0 (sin fundido desde negro). Hay un leve asentamiento de escala, después el barrido de acento y una deriva suave hasta el final.

**Datos:** ver `schema.json`.
